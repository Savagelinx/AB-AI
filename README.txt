AB AI — starter iPhone home-screen app

WHAT THIS VERSION DOES
- Provides the AB AI mobile interface.
- Can be installed as a Home Screen web app once hosted on an HTTPS website.
- Caches the app shell for basic offline opening.

IMPORTANT
This starter does NOT yet contain a connected AI model. The chat currently displays a setup message rather than pretending to generate AI answers. A real AI engine is the next step.

HOW TO PREVIEW
Open index.html in a browser for a basic preview. Service-worker installation requires hosting on HTTPS (or localhost).

HOW TO INSTALL ON IPHONE
1. Host the folder on an HTTPS site (we can use a free Vercel deployment).
2. Open the site in Safari on your iPhone.
3. Tap Share -> Add to Home Screen -> Add.

FREE AI
We will choose a model/provider with a free allowance or a local model. Free services can have usage limits and terms can change. Do not put a private API key directly in app.js or any browser code.
